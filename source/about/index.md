**XFM 主题文档站** 收录了由 XFM 开发并开源的两套 Hexo 主题的完整技术文档。

## 收录主题

| 主题 | 定位 | 仓库 |
| --- | --- | --- |
| hexo-theme-xfm | 高端大气的三模式主题（博客 / 笔记 / 文档） | [GitHub](https://github.com/xfm0797/hexo-theme-xfm) |
| hexo-theme-xongyi | 面向机构官网的通用主题（企业 / 政务 / 教育） | [GitHub](https://github.com/xfm0797/hexo-theme-xongyi) |

## 本站技术栈

本站自身即由 **hexo-theme-xfm** 的 `docs` 模式驱动，使用 Hexo 8 构建，文档侧栏树由 `source/_data/docs.yml` 定义。

{% note info 文档来源 %}
每篇文档均由对应主题仓库的 `README.md`、`_config.yml` 与 `examples/` 示例配置解析整理而成，力求与源码保持一致。
{% endnote %}
