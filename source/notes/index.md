**笔记** 收录的是本站自身的更新日志与建设记录 —— 从站点初始化、主题 submodule 化，到导航重构、文档迁移与形态调整，每一次改动都留一条记录。左侧导航按时间倒序列出全部笔记，点进任意一篇后仍会常驻，方便沿着时间线连续往下读。

{% note info %}
**文章与笔记的关系**

- **文章**（入口在首页 / 归档 / 分类 / 标签）：面向读者的技术内容，包含「开源项目」的项目档案，以及「设计」「前端」等实践文章；走博客形态，右侧带挂件栏与相关文章。
- **笔记**（本页）：面向站点本身的更新记录，统一归入 `更新日志` 分类；走笔记形态，左侧常驻导航、右侧正文目录，适合按时间线翻阅。
- 两者是**同一套文章系统的两个视角**：笔记本质上仍是普通文章（同样会出现在归档、分类与标签页），只是额外进入这份按时间组织的索引。
{% endnote %}
