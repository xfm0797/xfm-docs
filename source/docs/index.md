欢迎查阅 **XFM 主题文档**。本站收录两套由 XFM 开发并开源的 Hexo 主题的完整技术文档：面向长期写作的 **hexo-theme-xfm**，以及面向机构官网的 **hexo-theme-xongyi**。

> 文档内容由各主题仓库的 `README.md`、`_config.yml` 与示例配置解析整理而成，与源码保持同步。

## 收录主题

{% row %}

### hexo-theme-xfm

高端大气的**三模式** Hexo 主题：一套代码同时覆盖 **博客 / 笔记 / 文档** 三种形态，全套设计令牌驱动，形态几乎全部由配置决定。

- 三模式切换（blog / notes / docs）
- 自适应式三档响应式（mobile / tablet / desktop）
- 丰富标签插件与内容增强
- 内置全文搜索、目录、灯箱、数学公式、Mermaid

[开始阅读 →](/docs/xfm/)
{% endcol %}

{% col 6 %}
### hexo-theme-xongyi

面向机构官网的通用 Hexo 主题：内置 **企业 / 政务 / 教育** 三套预设布局与 **12 个可自由排序**的首页板块，60+ 项配置全部集中在 `_config.yml`。

- 三套预设：商务蓝 / 政务红 / 学院青
- 12 个首页板块，可启用 / 关闭 / 自由排序
- 暗色模式、完全响应式、SEO 友好
- 五大平台一键部署

[开始阅读 →](/docs/xongyi/)
{% endcol %}
{% endrow %}
