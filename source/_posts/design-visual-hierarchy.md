一个页面里所有元素都"很重要"，结果就是**什么都不重要**。

视觉层级的本质不是美观问题，而是**信息优先级的表达**——你让什么先被看到，用户就认为什么最重要。

<!-- more -->

## 一、五种建立层级的手段，权重不同

| 手段 | 强度 | 说明 |
| --- | --- | --- |
| **位置** | 最强 | 左上最先被看到（F 型阅读路径） |
| **尺寸** | 很强 | 大的先被注意 |
| **色彩/对比** | 强 | 高对比先被注意 |
| **留白** | 中等 | 被空白包围的元素更突出 |
| **字重** | 较弱 | 只在同一尺寸内有效 |

{% note danger 最常见的错误：手段之间互相打架 %}
标题用了大字号（强），但同时用了浅灰（弱）——两个信号冲突，结果层级模糊。

**多种手段要指向同一个方向**：重要的元素，位置靠前、尺寸更大、对比更强、留白更多、字重更重。
{% endnote %}

## 二、字号是层级的主力，但要克制

```css
h1 { font-size: 2.25rem; font-weight: 600; }
h2 { font-size: 1.75rem; font-weight: 600; }
h3 { font-size: 1.375rem; font-weight: 600; }
```

层级靠**跳跃**建立。如果 h1 是 24px、h2 是 22px、h3 是 20px，用户在滚动时根本分不清自己到了哪一级。

{% note tip 判断标准 %}
把页面截图缩小到 25%，如果你还能一眼看出标题/正文/辅助信息的三层结构，说明层级是成立的。看不出来就说明档位拉得不够开。

这也是为什么字号阶梯要用等比而非等差。
{% endnote %}

## 三、颜色：用对比度而不是"鲜艳度"做层级

三级文本的标准做法：

```css
--c-text:   #1b1f26;   /* 主：正文标题 */
--c-text-2: #5b6472;   /* 次：说明、元信息 */
--c-text-3: #8b94a3;   /* 弱：占位、禁用 */
```

{% row %}
{% col %}
**正确做法**

用**同一色相的不同明度**做层级。三级文本依然是同一个灰，只是深浅不同——整体协调。
{% endcol %}
{% col %}
**常见错误**

用不同颜色区分层级（正文黑、说明蓝、时间橙）。结果是页面像调色盘，**信息层级被颜色噪音淹没**。
{% endcol %}
{% endrow %}

{% note warning 颜色留给"含义"，不留给"层级" %}
颜色应该表达**语义**：品牌色 = 可交互，红色 = 危险，绿色 = 成功。

用它表达"这个字不那么重要"，会让用户困惑：蓝色说明文字是不是可以点？
{% endnote %}

## 四、留白是最被低估的手段

一个元素周围留白越多，它越突出——**即使它的字号没变**。

```
普通列表项：
[图标] 标题一
[图标] 标题二
[图标] 标题三

重要项：
        
[图标] ← 上下各 24px 留白 → 这一项自然成了焦点
        
[图标] 标题二
```

{% fold 为什么留白有效 %}
人眼的视觉分组遵循**邻近性原则**：距离近的元素被感知为一组，距离远的被分开。

所以留白不只是"呼吸感"，它是**分组工具**——你想让哪些内容被看成一体，就让它们靠得近；想让哪部分独立出来，就给它周围留白。
{% endfold %}

## 五、四个最常见的层级破坏行为

### 一、什么都加边框

每个卡片都加 `border`，结果是**边框的密度让所有卡片同等重要**，边框也就失去了分隔意义。

```css
/* 改进：用留白或极浅背景分组，边框只留给真正需要强调的 */
.card { background: var(--c-surface-2); border-radius: 8px; }
.card.is-featured { border: 1px solid var(--c-primary); }
```

### 二、按钮全都是主色

一屏里三个 `btn-primary`，用户不知道该点哪个。

{% note info 按钮层级规则 %}
**一屏之内只能有一个主按钮。** 其余用次级（描边）、文字按钮或图标按钮。

主按钮 = 你最希望用户做的那个动作。
{% endnote %}

### 三、强调滥用

**加粗**、*斜体*、~~删除线~~、高亮、下划线全用上，等于全没用。

一份文档里加粗的总量建议**不超过全文的 5%**——加粗应该像路标，而不是路面。

### 四、信息密度均质化

所有区块高度、间距、字号都一模一样，用户没有"锚点"可以定位。

解决：**给区块之间制造差异**。重要的区块更大、留白更多；次要信息紧凑排布。

## 六、三秒测试法

{% timeline %}
{% event 第一步 %}
打开页面，**只看 3 秒**然后关掉。
{% endevent %}
{% event 第二步 %}
写下你记住的三样东西。
{% endevent %}
{% event 第三步 %}
对照你希望用户记住的三样东西。
{% endevent %}
{% endtimeline %}

如果两者不一致，说明视觉层级表达的不是你的意图——需要调整的是**权重分配**，而不是加更多装饰。

{% note tip 为什么是 3 秒 %}
用户在真实场景里给一个页面的时间通常不到 3 秒。这不是"用户没耐心"，而是**信息过载环境下的正常筛选行为**。

页面必须在 3 秒内回答"这是什么、我能干什么、我该点哪"。
{% endnote %}

## 七、内容型页面 vs 功能型页面

两类页面的层级策略不同：

{% row %}
{% col %}
**内容型（文章、文档）**

层级服务于**阅读顺序**：标题 > 正文 > 引用/代码 > 注释。

重点是**扫描性**——用户应该能通过标题快速定位。所以标题层级要清晰、间距要分组。
{% endcol %}
{% col %}
**功能型（列表、表单、控制台）**

层级服务于**操作优先级**：主操作 > 当前状态 > 次要信息。

重点是**可行动性**——用户应该立刻知道下一步做什么。
{% endcol %}
{% endrow %}

## 八、无障碍视角的层级

视觉层级对**无法看见的用户**是不存在的。所以要同时提供语义层级：

```html
<h1>文章标题</h1>
  <h2>章节一</h2>
    <h3>小节</h3>
  <h2>章节二</h2>
```

{% note danger 不要跳级，不要为了字号选标题级别 %}
用 `h4` 只是因为它字号小——这是最常见的语义错误。标题级别表达的是**文档结构**，不是字号。

字号由 CSS 控制，级别由内容结构决定。**用 `h2` 配一个较小的 class 是完全合理的。**
{% endnote %}
