**XFM CMS** 是一套基于 PHP 7.4 + SQLite / MySQL 的轻量级企业官网程序，专为产品展示型小微企业设计。零外部依赖，默认使用 SQLite 单文件数据库，也可切换到 MySQL / MariaDB 应对更高并发。

<!-- more -->

## 前台能力

- **首页**：轮播横幅 + 公司新闻 + 产品中心（左栏分类 / 右栏四列卡片）+ 关于 / 联系并排
- **轮播横幅**：背景图或渐变色、自动播放、左右箭头、指示点、触摸滑动、键盘方向键
- **公司新闻**：列表分页、详情页（封面图、摘要引言、Markdown 正文、相关新闻、浏览统计）
- **产品中心**：分类导航 + 卡片网格、关键词搜索、详情页多图画廊与规格参数表
- **联系我们**：留言表单（带验证、防灌水、AJAX 提交）
- **SEO 与体验**：伪静态 URL 可开关、自动生成 sitemap.xml、全响应式、资源压缩与 Gzip

## 后台能力

独立登录入口（`password_hash` 加密）、仪表盘统计、横幅 / 新闻 / 产品 / 分类 / 留言的增删改查、多图上传、推荐与排序、发布状态控制。

## 部署

**方法一（推荐）**：把源码上传到虚拟主机即可，默认识别 SQLite，无需配置数据库。
**方法二**：本地用 PHP 内置服务器预览。

README 中还附有免费虚拟主机部署指南与数据库保护建议。
